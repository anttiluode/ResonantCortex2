# ResonantCortex2 V2/V3 — Causal Control Substrate + Global Consistency

## Status

Design specification for the next architectural stage after V1 Computation Autopsy.

V1 established a specific failure: locally good compressed state-transition modes do not remain reliable under repeated composition. On Mandelbrot and parity, one-step error is small while fixed-route rollout error grows rapidly. One-step successor lookahead helps but does not close the loop. V2 therefore removes learned state-transition dynamics from the compiled object entirely.

The new hypothesis is:

> Search should discover **controls over a trusted causal substrate**, not approximate the substrate's state transition law.

V3 then tests the separate MovingProblem-style failure mode:

> A sequence can be locally legal at every step and still be globally wrong after composition.

The implementation must preserve the V0/V1 receipts and Gates 0–7 unchanged.

---

# 1. Scientific question

V2 asks:

> If the state evolution is generated by a fixed, deterministic, causal dynamical system, can search discover useful control trajectories, can those trajectories be compressed into reusable state-conditioned control motifs, and can the frozen motif policy generalize on held-out initial conditions without the rollout drift seen in V1?

V3 asks:

> Even when every step is generated by the trusted substrate and every local policy decision is admissible, can we detect globally inconsistent compositions using explicit cycle/invariant tests?

A passing result is **not** a general program-synthesis claim. It is evidence for policy discovery and compression over one fixed family of nonlinear dynamical substrates.

---

# 2. Approaches considered

## A. Project V1 predictions back onto the cable manifold

Keep learned state-transition modes, then apply a cable step or projection after each prediction.

**Rejected as the primary arm.** It leaves the learned mode pretending to be the causal law. The projection could hide model errors without proving that search discovered a policy.

## B. Cable + learned residual dynamics

Use

```text
x_(t+1) = F_cable(x_t, u_t) + delta_i(x_t)
```

with a small learned residual.

**Rejected for V2.** The residual can become a hidden second simulator and reintroduce the exact composition ambiguity V2 is meant to remove.

## C. Fixed causal substrate; search and compress controls only

Use

```text
u_t = policy(x_t, input_t)
x_(t+1) = F_causal(x_t, u_t, input_t)
```

where `F_causal` is fixed before search and is never fit from successful trajectories.

**Selected.** This is the cleanest test of whether search→compression→autonomous control works once state evolution is compositionally lawful by construction.

---

# 3. Causal substrate

V2 uses a small browser/Node-compatible state-space circuit inspired by Operaattori's extracted causal runtime, not a biological accuracy claim and not a port of cell-1125 data.

The substrate state is an `n`-vector `x_t`. A fixed passive graph is compiled once into one-step matrices:

```text
P = A^-1 D
X = A^-1 B
A = D + G
D = diag(C / dt)
```

so that the passive update is

```text
x_passive = P x_t
```

and a small set of nonlinear sites receives a bounded control vector `u_t`.

For nonlinear site voltages `z`, solve a local implicit closure:

```text
z = S x_passive + R J(z, u_t)
```

with Newton iteration, where `J` is a fixed saturating voltage-dependent current law. After convergence:

```text
x_(t+1) = x_passive + X J(z, u_t)
```

The exact current law need not reproduce NMDA quantitatively. It must have the same architectural role: fixed nonlinear local feedback embedded in fixed linear transport.

### Substrate constraints

- No trainable substrate parameters.
- No task-specific substrate rewiring.
- Same `P`, `X`, nonlinear law, site positions, and integration step for every V2 primary task.
- Controls are bounded per site.
- Every substrate step reports Newton convergence, residual, and safety-clamp status.
- A failed implicit solve is a failed control step; search may not bypass it.
- Search never receives derivatives or backpropagates through the substrate.

---

# 4. What search is allowed to discover

Search candidates are **control policies**, not transition models.

A candidate policy is a small sequence/bank of generic control units. Each unit computes a bounded control vector from current observable state and current external input:

```text
u = umax * tanh(Wx + Vin + b)
```

Optionally, a scalar soft gate may modulate each unit:

```text
g = sigmoid(k (q^T x + r^T input + c))
u <- g u
```

Search may mutate only policy parameters. The substrate remains frozen.

Two search generators remain required:

- evolutionary search;
- simulated annealing.

They operate over the same policy representation and receive only final task score, never oracle intermediate state targets.

---

# 5. Compression target changes from transitions to controls

V1 compressed:

```text
(state_t, state_(t+1))
```

into local affine transition modes.

V2 compresses:

```text
(state_t, external_input_t, successful_control_t)
```

into reusable control motifs.

A control motif contains:

- source-state prototype/scale or learned low-rank source subspace;
- optional input prototype/scale;
- affine control decoder;
- applicability threshold;
- source solver provenance for cross-solver analysis only.

The frozen compiled policy routes by source applicability and emits a control vector. The next state is always generated by the causal substrate.

No compressed object may directly set or predict `x_(t+1)`.

# 6. V2 benchmark split

The old V0 tasks remain in the report as **out-of-family controls**. They do not determine V2 success.

## Primary natural tasks

All use the same fixed substrate.

### T1 — Persistent toggle / parity

Input: a sequence of sparse binary pulses.

Goal: final readout equals parity of pulses.

Why natural: requires a persistent state that conditionally flips.

Held-out split: longer sequences than search, unseen pulse timings.

### T2 — Delayed copy

Input: one signed pulse followed by a silent delay.

Goal: reproduce pulse sign after the delay.

Why natural: tests memory retention without arithmetic structure.

Held-out split: delays longer than search delays and amplitudes between trained amplitudes.

### T3 — Temporal pattern discrimination

Input: two pulse families with equal total energy but different ordering/timing.

Goal: classify family at sequence end.

Why natural: requires temporal integration plus state-sensitive nonlinear response.

Held-out split: unseen jitter and amplitude scaling.

### T4 — Stateful switch / context gate

Input: context pulse selects one of two later signal channels to preserve in the final readout.

Goal: output the channel selected by the earlier context.

Why natural: requires memory plus conditional routing.

Held-out split: unseen context-to-signal gaps and signal amplitudes.

## Out-of-family controls

Retain parity's old V0 implementation, sort4, GCD, and Mandelbrot as non-gating controls. Their purpose is to measure the ceiling of this substrate, not to force a pass.

No task is removed from historical reporting.

---

# 7. V2 baselines

Every primary task reports:

1. **Search-only policy** — best discovered policy executed directly on held-out instances.
2. **Compressed control motifs** — frozen routed control bank, no search at inference.
3. **Global control map** — one affine state/input→control map fit to pooled successful controls.
4. **Nearest-trajectory control** — nearest successful source state replays its stored control.
5. **No-control substrate** — all-zero control.
6. **Random matched control policy** — parameter-count-matched random policy.

Optional tiny-neural baseline may remain, but it cannot replace the required baselines above.

# 8. V2 gates

Existing Gates 0–7 remain byte-for-byte semantically unchanged.

## Gate 8 — CAUSAL_SUBSTRATE_VALID

Pass only if all of the following hold:

- 100% of zero-control and bounded-random-control test steps remain finite;
- at least 99.9% of implicit nonlinear site solves converge within the fixed iteration limit;
- deterministic replay of the same state/input/control sequence is bitwise identical in JS number output serialization;
- perturbing a control changes the next state while changing no substrate parameter;
- direct state overwrite is impossible through the public policy execution interface.

This is an engineering/scientific substrate integrity gate, not task success.

## Gate 9 — SEARCH_FINDS_CONTROLLABLE_TASKS

Pass if at least **3 of 4 primary tasks** satisfy on held-out instances:

- search-only score >= 0.85;
- for binary/exact tasks, exact accuracy >= 0.80;
- best search policy beats no-control by >= 0.20 score;
- both search generators independently produce at least one trajectory with instance score >= 0.80.

This proves the fixed substrate is controllable enough for the chosen task family.

## Gate 10 — CONTROL_COMPRESSION_GENERALIZES

Pass if at least **2 primary tasks** satisfy all of:

- compressed-policy score >= 0.90 * search-only score;
- compressed-policy score exceeds global-control-map score by >= 0.10 **or** exact accuracy exceeds it by >= 0.15;
- compiled inference uses zero search evaluations;
- UNKNOWN/control-abstention rate <= 0.10;
- at least one passing task uses >=2 motifs on held-out data.

This is the main V2 claim gate.

## Gate 11 — COMPOSITION_SURVIVES_HORIZON

For each task, compare teacher-state motif selection with autonomous motif rollout over aligned successful trajectories and held-out trajectories.

Pass if at least **2 Gate-10 tasks** satisfy:

- horizon-1 normalized endogenous divergence <= 0.05;
- horizon-8 divergence <= 0.10;
- horizon-8 divergence is <= 2.0x horizon-1 divergence plus 0.02;
- no more than 10% of held-out episodes leave all learned motif applicability regions before task completion.

Unlike V1, state evolution itself is exact under the substrate; this gate tests policy composition rather than learned-dynamics drift.

# 9. V3 global consistency / holonomy fence

V3 is deliberately separate from V2 task success.

Local legality means only:

- selected motif accepts current state/input;
- control is within bounds;
- substrate step converges;
- next state remains finite.

That is insufficient for global correctness.

## Closed-loop probe family

Add controlled loop tasks where the intended external operation returns the observable task configuration to its start after a finite sequence, while a hidden/global invariant determines whether the internal computation also returned correctly.

Three required probes:

### L1 — Double toggle

Two identical toggle commands should return the persistent bit to its original value.

### L2 — Pulse / inverse-pulse cycle

A positive control context followed by its matched inverse should restore a designated readout/invariant within tolerance.

### L3 — Permuted closed cycle

Use two locally admissible control motifs A and B. Compare closed sequences `AB A^-1 B^-1` and `BA B^-1 A^-1` (implemented through fixed signed control templates, not symbolic inverses). They share local admissibility checks but may accumulate different hidden state.

The purpose is not to claim mathematical gauge holonomy. It is an executable analogue of the MovingProblem warning: local checks can stay green while a closed composition returns the wrong global state.

## Global consistency monitor

For every completed loop, compute:

- readout closure error;
- full-state closure error on designated invariant coordinates;
- motif sequence;
- maximum local applicability residual;
- maximum substrate Newton residual;
- whether every local legality check passed.

The monitor is post-hoc/diagnostic in V3. It may not alter the policy during the first V3 experiment.

## Gate 12 — LOCAL_LEGALITY_NOT_GLOBAL_CORRECTNESS

This is an adversarial demonstration gate.

Pass if the fixed test set contains at least one policy/loop episode where:

- every local legality check passes;
- all substrate steps converge;
- no control bound is violated;
- but global closure error exceeds the preregistered failure tolerance of 0.10 normalized units.

If no such case exists, Gate 12 records FAIL/NOT_DEMONSTRATED rather than manufacturing one.

## Gate 13 — GLOBAL_MONITOR_DETECTS_COMPOSITION_FAILURE

Pass if, on a frozen labeled set of good and bad loop episodes:

- bad episode recall >= 0.90;
- good episode false-positive rate <= 0.10;
- monitor uses only loop-level invariant/closure quantities and does not inspect final task labels;
- threshold is chosen on a calibration split and frozen before held-out evaluation.

This gate tests detection, not prevention.

---

# 10. Data separation and anti-cheating rules

- Search receives final scalar task score only.
- Search receives no oracle intermediate states, reference controls, or motif assignments.
- Compression receives only trajectories from search episodes meeting the fixed success threshold.
- Compression may see successful controls because controls are the object being compiled.
- Held-out evaluation instances are generated from disjoint deterministic seeds and broader timing/amplitude ranges.
- V3 monitor thresholds are calibrated on separate loop episodes from final held-out loop evaluation.
- Solver identity may be recorded for analysis but may never be an input feature.
- Old task reference algorithms remain evaluation-only.
- No gradient/backpropagation through the causal substrate is used in the primary V2 arm.

# 13. Interpretation rules

Allowed if Gates 8–11 pass:

> A fixed nonlinear causal substrate can be programmed by search-discovered controls; those successful controls can be compressed into a reusable state-conditioned motif policy that generalizes on held-out temporal tasks without the learned-transition rollout drift observed in V1.

Not allowed:

- general algorithm discovery;
- general program synthesis;
- biological learning mechanism claims;
- arbitrary symbolic computation claims;
- claims that local legality guarantees global correctness.

Allowed if Gate 12 passes:

> The system contains executable cases where all local control/substrate checks pass while a closed composition is globally inconsistent.

Allowed if Gate 13 passes:

> A separate loop-level consistency monitor detects most such globally bad compositions on held-out loops without using task labels.

---

# 14. Expected scientific outcomes

All outcomes are acceptable:

1. **Gate 9 fails:** the chosen substrate is not controllable enough even for natural temporal tasks. Stop; do not tune compression.
2. **Gate 9 passes, Gate 10 fails:** search can program the substrate, but successful controls do not compress into reusable motifs.
3. **Gate 10 passes, Gate 11 fails:** compressed motifs generalize one-step/short-horizon but still compose poorly as policies even though state dynamics are lawful.
4. **Gates 8–11 pass:** V2 succeeds as a narrow policy-discovery result.
5. **Gate 12 passes:** local legality is empirically insufficient for global closure in this substrate.
6. **Gate 13 passes:** V3 demonstrates a useful separate global-consistency detector.

No threshold may be changed after seeing the default receipt without creating a new explicitly versioned gate.
